# Oil & Gas RAG - Demo

Live page: https://siljepettersson.github.io/oil-gas-rag-demo/

Static demo of [oil-gas-rag](https://github.com/siljepettersson/oil-gas-rag): retrieval-augmented question
answering over synthetic oil & gas documents and a P&ID process graph. Answers were computed ahead of time and
are shown with their claims, sources, tool calls, evaluation and the evidence drawn on the P&ID. No server, no
API calls. All data is synthetic.

Generated with `uv run oilgas-rag export-static` in the main repository.
